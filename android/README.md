# dbsx 安卓版 —— 云端构建指南（无需在本机安装任何工具）

## 原理
把安卓工程上传到 GitHub，GitHub 的免费服务器（GitHub Actions）自动完成编译，你在网页上下载 APK。

## 操作步骤（约 10 分钟，只需一个浏览器）

### 第 1 步：注册 GitHub（5 分钟）
1. 打开 https://github.com  → 点 **Sign up** 注册（免费，邮箱验证一下）
2. 登录

### 第 2 步：新建仓库
1. 右上角 **+** → **New repository**
2. Repository name 填：`dbsx`
3. 选 **Private**（私有，只有你能看）或 Public 都行
4. 点 **Create repository**

### 第 3 步：上传工程文件
1. 在刚建的仓库页面，点 **"uploading an existing file"** 链接
2. 把本文件夹 **`android` 整个文件夹拖进上传区域**（Chrome/Edge 支持拖文件夹，目录结构会自动保留）
   - ⚠️ 如果拖进去看不到 `.github` 文件夹：改用「Add file → Create new file」，路径填 `.github/workflows/build-apk.yml`，把本文件 `build-apk.yml` 的内容复制粘贴进去（其他文件正常拖）
3. 点 **Commit changes**

### 第 4 步：等待云端编译（3~6 分钟）
1. 仓库顶部点 **Actions** 标签
2. 会看到 "Build APK" 正在运行（黄色 ⏳）→ 等它变绿色 ✅
   - 如果变红色 ❌：点进去看是哪一步报错，把报错截图发我，我来修

### 第 5 步：下载 APK
1. 点击那次绿色运行的条目
2. 页面底部 **Artifacts** → 下载 **dbsx-apk**（zip）
3. 解压得到 `app-debug.apk`

### 第 6 步：安装到手机
1. 把 `app-debug.apk` 通过 QQ/微信/数据线传到手机
2. 手机上点击安装 → 系统提示"未知来源"时选择**允许/继续安装**
3. 完成！桌面上出现「dbsx 待办」

## 使用说明
- 数据保存在**应用内部存储**，每次修改自动保存，卸载应用才丢失
- 🔔 **通知提醒**：截止**前 24 小时**（或已逾期）自动推送系统通知；后台每 15 分钟检查一次，手机重启后自动恢复；每天每项最多提醒一次。首次打开请**允许通知权限**（Android 13+ 会弹窗询问）
- 右上角「导入备份」可恢复之前导出的 JSON 数据
- 建议定期把数据导出备份（在网页版里操作：网页版点「导出」→ 生成 JSON → 手机版「导入备份」）

## 以后改功能怎么办
改完 `dbsx_mobile.html` 后：
1. 重新运行 `node make_apk_asset.cjs`（在 dbsx 文件夹，会重新生成安卓用的网页文件）
2. 把改动的文件上传到 GitHub 仓库（覆盖上传）
3. Actions 自动重新编译 → 重新下载 APK

## 常见问题
| 问题 | 解决 |
|---|---|
| Actions 标签是空的 | 可能仓库还没触发，随便再上传一次文件即可 |
| 编译报错 | 把红色步骤的日志截图发给我 |
| 手机装不上 | 安卓版本低于 7.0（API 24）不支持；或先卸载旧版本 |
| 提示"已安装更高版本" | 卸载手机上的旧版再装 |
